The **Rule of Three** (known in German as *Dreisatz*) is a classic mathematical method for solving proportion problems where three values are known and an unknown fourth value (**X**) must be calculated.

Proportional problems fall into two distinct categories:
1. **Direct Proportion**: As input A increases, output B increases at the exact same ratio (e.g., scaling a recipe from 4 servings to 10 servings, or calculating fuel consumption over distance).
2. **Inverse Proportion**: As input A increases, output B decreases proportionally (e.g., adding more builders reduces the total days required to complete a renovation project).

## ⚙️ Rules & Thresholds

- **Direct Proportion Rule**:
  - Premise: `A -> B` and `C -> X`.
  - Cross-Multiplication Formula: **`X = (B × C) / A`**.
  - Example: If 4 kg of flour costs £6, how much does 10 kg cost? `X = (6 × 10) / 4 = £15.00`.
- **Inverse Proportion Rule**:
  - Premise: `A -> B` and `C -> X`.
  - Inverse Formula: **`X = (A × B) / C`**.
  - Example: If 4 workers build a wall in 6 days, how long do 8 workers take? `X = (4 × 6) / 8 = 3 Days`.

## 📑 Common Pitfalls

- **Confusing Direct and Inverse Proportions**: Applying the direct proportion formula `(B × C) / A` to a project timeline problem where adding workers actually speeds up work produces an incorrect, impossibly large answer!
- **Dividing by Zero**: Ensure neither value A nor value C equals zero when entering proportion calculations.
- **Forgetting Unit Alignment**: Ensure values A and C use the same measurement unit (e.g. both in kilograms or both in grams) before cross-multiplying.

  <div class="faq-item">

    <div class="faq-content">
      <p>Ask: "If I increase the first number, will the result increase or decrease?" If the result increases (e.g. buying more items costs more money), it is direct proportion. If the result decreases (e.g. driving faster reduces travel time), it is inverse proportion.</p>
    </div>
  </div>

  <div class="faq-item">

    <div class="faq-content">
      <p>Yes. Currency conversions follow direct proportion. If £100 GBP gives €117 EUR (A -> B), then £250 GBP (C) gives `(117 × 250) / 100 = €292.50 EUR` (X).</p>
    </div>
  </div>

  <div class="faq-item">
